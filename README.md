# Ociosos (Idle Hero) 🦸‍♂️🦸‍♀️

## O que é esse jogo? 🤔
É um joguinho bem simples de gerenciar uma agência de super-heróis!
Você contrata heróis, escolhe onde eles vão trabalhar (fazendo patrulha, investigando, etc) e manda eles para missões. Tudo isso no estilo *idle* (onde o jogo trabalha pra você enquanto você gerencia os recursos).

## Como fazer rodar? 🚀

### Jeito Super Fácil:
1. Para **ligar** o jogo: Rode o script `./up.sh` no terminal.
2. Para **desligar**: Rode o script `./down.sh`.

*(Se você usar o `./up.sh`, o jogo vai rodar quietinho no fundo e você pode fechar o terminal!)*

### Jeito "Desenvolvedor" (Manual):
Se quiser rodar manualmente, abra o terminal e digite:
```bash
cd game
npm install
npm run dev
```

Prontinho! Agora é só abrir o link local que aparecer no terminal (geralmente `http://localhost:5173`) e jogar! 🎉
