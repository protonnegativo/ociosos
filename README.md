# Ociosos (Idle Hero) 🦸‍♂️🦸‍♀️

## 🚀 Como fazer rodar?

**Jeito Super Fácil:**
1. Ligar o jogo: `./up.sh`
2. Desligar o jogo: `./down.sh`

**Jeito Manual:**
```bash
cd game
npm install
npm run dev
```
*(Acesse o link local gerado, geralmente `http://localhost:5173`)*

## 🤔 O que é esse jogo?

É um joguinho bem simples de gerenciar uma agência de super-heróis! Você contrata heróis, escolhe onde eles vão trabalhar (patrulha, investigando, etc) e os envia para missões no estilo *idle*.
